# ジャンクション・シミュレーター

高速道路のIC（インターチェンジ）やJCT（ジャンクション）で、合流・分岐による車の流れと渋滞をシミュレーションするブラウザアプリです。

**▶ ブラウザで遊ぶ: https://isthd.github.io/junction-simulator/**

手元で使う場合は `index.html` をブラウザで開くだけで動きます（インストール不要）。

### アプリとして使う・オフラインで使う

公開ページを一度開くと、以降は電波がなくても動きます（アプリ本体とフォントを端末に保存します）。

- **iPhone / iPad（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android / PC（Chrome・Edge）**：メニュー →「アプリをインストール」（またはアドレスバーのインストールボタン）

ホーム画面のアイコンから、アプリのように全画面で起動できます。オンライン時は毎回最新版を読み込みます。

## できること

- **ランダムな街をながめる**（最初に開くとこれが表示されます）
  - 「別の街をつくる」を押すたびに、形の違う街ができる。ゆがんだ格子状の一般道、信号つきの交差点、道ぞいの家・会社・お店、街を横切る高速道路とICがある
  - 車は行き先を持って走る。朝は家から会社へ、夕方は会社から家へ、昼はお店へと流れが変わり、朝夕のラッシュで渋滞ができては引いていく
  - 車は混み具合を見て経路を選び、走っている途中でも、先が詰まっていれば別の道へ回る
  - 信号は、青の方向に車が来なくなったら切り替わる（感知式）。右折車は対向車を待つ
- **時間と天気**
  - 1日の流れ（朝夕のラッシュ・昼と夜）。夜は暗くなり、ヘッドライト・テールランプ・建物の窓あかりがつく。「朝 7時」などのボタンでその時刻へ進める
  - 天気：ときどき雨が降る（雨の日はみんな少しゆっくり、車間も広め）。ずっと晴れ・ずっと雨にもできる
  - うっかりブレーキ：ドライバーがときどき理由なくブレーキを踏む。車が多いと、原因のない渋滞（自然渋滞）が後ろへ伝わっていく
  - 車の種類と性格：乗用車・せっかちな車・のんびりな車・大型トラック・バス。「車の色」を「車の種類・性格別」にすると見分けられる
- **車を追いかける**
  - 「車を追う」（Fキー）か、観察モードで車をタップすると、その車をカメラが追いかける。行き先までの経路と「信号待ち」「右折待ち」「渋滞で止まっている」などの様子が出る
  - 着いたら自動で次の車へ（切り替え可）
  - 「渋滞スポットを見る」で、いちばん詰まっている所へ移動できる
- **IC・JCTを選ぶ**
  - IC：トランペット型IC（料金所つき）、ダイヤモンド型IC
  - JCT：Y型JCT、トランペット型JCT、クローバー型JCT
- **交通量を変える**
  - 深夜／平常／朝夕ピーク／連休渋滞の切り替え、0〜300%の倍率
  - OD表で「どの入口からどの出口へ何台/時」を指定
  - 大型車の混入率、合流に必要な車間（秒）
- **オリジナルのIC・JCTを作る**
  - 「道路を描く」でマップを指やマウスでなぞるだけで、その線がなめらかな道路になる
    - 「おまかせ」では一般道（両方向・左側通行）になる。一般道どうしが交わると、自動で信号つきの交差点になる。何にもつながっていない端には家・会社・お店のどれかが建つ（選択モードで変えられる）
    - 高速道路の道路につなぐとランプ（一方通行。描いた向きが進行方向）になる。種類を「本線」「ランプ」「料金所」にすると一方通行の高速道路として描ける
    - 既存の道路から描き始めると分岐、既存の道路で描き終えると合流になり、道路の向きに沿って自然につながる
    - 道路の種類（本線／ランプ）と制限速度はカーブのきつさから自動で決まる（手動指定も可）
    - 途中で他の道路と交差しても立体交差として扱われ、つながらない
  - 「選択・移動」で点やカーブをドラッグして形を調整（道路をダブルクリックでカーブ点を追加）
  - 道路ごとに本線／ランプ／料金所と制限速度を設定。合流では本線が優先
  - 名前をつけてブラウザに保存、JSONで書き出し・読み込み
- **2D／3Dを切り替える**
  - 画面上部の「2D｜3D」で切り替え。3Dでは立体交差が高架になり、橋脚や影つきで立体的に見られる
  - どの道路が上を通るかは自動で決まる（ランプ・料金所は本線の上、同じ種類なら上り下りの余裕がある方が上）。一般道は高速道路の下をくぐる
  - 3Dのままでも道路を描く・選択して動かす・削除するができる（描いた道路もすぐ立体で表示される）。編集中の視点は右ドラッグ・2本指で動かす
  - 最後に選んだ表示はブラウザが覚えている
- **結果を見る**
  - 走行台数、流入待ち、平均速度、平均遅れ、出口ごとの通過量
  - 道路を渋滞度で色分け（緑＝順調、黄＝混雑、赤＝渋滞）

## 操作

| 操作 | 方法 |
| --- | --- |
| 再生・一時停止 | スペースキー |
| 車を追う・やめる | F / Esc（観察モードで車をタップでも追える） |
| モード切替 | V 観察 / S 選択 / R 描く / D 削除 |
| 2D／3D切替 | 2 / 3 |
| 3Dの視点 | 観察：ドラッグで回転、右ドラッグ・2本指で移動、ホイール・ピンチで拡大<br>編集中：右ドラッグ・2本指で移動、Shift＋右ドラッグで回転、ホイール・ピンチで拡大 |
| 拡大・縮小 | マウスホイール、2本指ピンチ |

## モデルについて

- 車の動きは追従モデル（IDM）で計算しています
- 合流では、ランプ側の車が本線の車との間隔を見て入ります
- 車線はすべて1車線として扱い、車線変更はありません（一般道は片側1車線ずつ）
- 建物がある設計では、行き先は建物の種類と時間帯で決まります（OD表は使いません）。建物のない IC・JCT はこれまでどおり OD表で、1日の流れがオンのときは時間帯で量が変わります
- 一般道が混みすぎると、街に入る車を流入待ちで待たせます。それでも一般道で2分以上まったく動けなくなった車は、近くの駐車場に入ったものとして消えます（街全体が詰まって止まり続けるのを防ぐため）
- ダイヤモンド型ICの一般道側の信号は省略しています
- 3D表示の高さ（高架）は見た目だけで、坂による速度の変化は計算していません
- 3D表示には [three.js](https://threejs.org)（MIT License）を使っています（`vendor/three-bundle.js`。3Dを選んだときだけ読み込みます）
